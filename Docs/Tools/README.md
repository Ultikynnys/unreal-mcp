[REFERENCE.md](REFERENCE.md) is generated from the registered tools and lists all of
them with their exact parameters. It is the authoritative list: where a prose page and
the reference disagree, the reference is right. `Python/scripts/test_docs_parity.py`
fails if any page here documents a tool that does not exist, or if the reference is
stale.
